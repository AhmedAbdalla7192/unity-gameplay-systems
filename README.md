# Unity gameplay systems

Reusable gameplay systems from my own games, packaged so they can be read, tested and installed on their own. All code by Ahmed Abdalla ([LinkedIn](https://www.linkedin.com/in/ahmedabdallacs/) · [itch.io](https://dragonveil.itch.io)).

| Package | What it is |
|---|---|
| [`com.dragonveil.statemachine`](Packages/com.dragonveil.statemachine) | Hierarchical state machine with prioritised transitions, transition steps and a tick-authority hook for networked games. Used for the player controllers in Soul Heist. |

The repository is a Unity 6 (6000.3) project. Open it in Unity to browse the packages and run their tests.
